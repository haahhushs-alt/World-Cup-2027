World Cup 2027 v0.3.0｜iPad 横屏离线足球

安装
使用 Safari 下载 WorldCup2027-v0.3.0.ipa。如果浏览器打开文件预览，请改用仓库首页的 ZIP 下载链接，解压后会得到同一个 IPA。安装前需自行签名。

操作
触屏在左下区域按住滑动即可移动。射门上滑挑射、下滑弧线、左滑假射、右滑暴力射门。传球上滑高传、下滑传后跑位、左滑大力射门、右滑半高球。直塞上滑高球直塞、左滑大力直塞。冲刺键在对手持球时可尝试断球。

使用系统识别的扩展手柄时，默认左摇杆移动，A 传球，B 按住蓄力、松开射门，Y 直塞，RT 冲刺。菜单和暂停界面均可修改键位。手柄支持以 iPadOS 实际识别结果为准。

本版
新做了四张原创人脸纹理，重塑鼻梁、眼窝和下颌，增加发丝、球鞋和手部细节。跑步时膝盖和脚踝随步态弯曲，带球触球点跟随步伐。队友会迎接短传、追赶直塞和传后前插。在接球前按下传球或射门，可在第一脚触球时按输入方向出球。
进球有球网形变和近景庆祝。18 组离线声音包括带球触球、撞网和擦门而过时的看台反应。
iPad Pro 2021、iPadOS 26.0.1 和黑武士 3 Pro 的真机组合尚待实测。本作使用原创球队、球员和卡面，足球规则覆盖主要判罚。

工程
game/ 为离线游戏资源，ios/ 为原生宿主。在安装 Xcode 的 Mac 上运行 sh ios/scripts/package.sh 可构建未签名 IPA。运行 node tools/check-match.cjs 可复测传接球与点球流程。
