World Cup 2027 0.2.0｜iPad 离线足球

本版更新
- 15组原创合成离线音频，包含观众、助威、传射、扑救、脚步、门框、落地、抢断、哨声、终场哨、菜单音乐和界面反馈。
- 总音量、观众、比赛音效与音乐分别调节并保存，暂停时降低球场音量。
- 蓝色比赛界面、低角度转播镜头、动态阴影、小地图、射门力度条。
- 带球步点、球员避让和无球时抢断/切人按键。
- 修复下半场补时状态未重置。

IPA 未签名，需要自己的签名方式才能安装。兼容目标为2021 iPad Pro，iPadOS 16及以上。iPadOS 26.0.1和黑武士3 Pro仍需真机验证。
球员、卡面与音频为原创资源，当前建模和动作仍是独立游戏原型水准。浏览器功能已测试，足球规则只覆盖已实现的主要判罚。

game/ 为游戏资源；ios/ 为原生宿主。macOS 上运行 sh ios/scripts/package.sh 重新编译。GitHub Actions 工作流在仓库根目录 .github/workflows/ipad.yml。
